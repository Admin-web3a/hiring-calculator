# Hiring calculator

Внутренний калькулятор мотивации для контент-вакансий Web3 Academy: доход специалиста по прогрессивной шкале бонуса от выручки и экономика направления.

Одна самодостаточная HTML-страница без сборки и зависимостей. Публикуется через GitHub Pages из `main` + `/docs`. Адрес страницы не публикуется в репозитории — он есть в Notion-странице вакансий.
